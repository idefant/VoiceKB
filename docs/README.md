# Документация VoiceKB

Документация — источник истины о поведении системы и о принятых решениях, а не запоздалые заметки. Сначала читаем нужный слой, потом меняем код, потом приводим документацию в соответствие.

## Слои документации

| Вид | Где | Что описывает | Чего НЕ содержит |
| --- | --- | --- | --- |
| Функциональная спецификация | `docs/functional-spec/` | Только пользовательское взаимодействие и наблюдаемое поведение системы | Технические детали, названия классов/методов/файлов, ключи настроек, API |
| Документация разработки | `docs/development/` | Сложные решения: почему так сделано, что подразумевает, где слабые места | Пересказ кода, таблицы с перечнем файлов, тривиальные решения |
| Правила разработки | `docs/development-guidelines.md` | Как писать код в этом проекте: стек, команды, конвенции, проверки | Почему сделали фичу, что видит пользователь |
| Шаблоны | `docs/templates/` | Заготовки для нового раздела ФС и нового дока разработки | — |

Реестры (каждый новый документ регистрируется в своём):

- [Реестр функциональной спецификации](functional-spec/README.md)

## Обязательный протокол

1. ПЕРЕД работой над функционалом прочитай соответствующий раздел ФС и связанный с ним док разработки.
2. Если изменение ЛОМАЕТ задокументированное поведение — ОСТАНОВИСЬ, предупреди пользователя и спроси, действительно ли это нужно. Не меняй задокументированное поведение молча.
3. ПОСЛЕ изменения приведи ФС в соответствие новому поведению; для сложных решений обнови или добавь док разработки (почему / следствия / слабые места).
4. Если код УЖЕ расходится с документацией — опиши расхождение словами (не кодом) и предложи исправить документацию.

## Правила оформления

- Не делай ручной перенос строк по ширине (80/100 символов). Один абзац или пункт списка — одна строка; перенос по словам делает редактор.
- Разделяй блоки (абзацы, пункты, заголовки, код) пустой строкой.
- Язык документации — русский.
- Тон ФС: нейтральный контрактный язык от третьего лица о поведении. Тон дока разработки: рассуждение о причинах и следствиях.
