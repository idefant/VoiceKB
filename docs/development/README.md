# Реестр документации разработки

Каждый док разработки описывает ОДНУ предметную область: сложные решения — почему так сделано, что подразумевает, где слабые места. Простые и очевидные решения сюда не добавляются. Новый док создаётся из шаблона `docs/templates/development-doc-template.md` и обязательно добавляется в таблицу ниже.

| Область | Файл | Описание |
| --- | --- | --- |
| Жизненный цикл IME и голосовой сессии | [ime-session-lifecycle.md](ime-session-lifecycle.md) | Как из шумных колбэков IME выводится намерение пользователя: латч мгновенной записи, временный режим, сохранение сессии при диалогах |
| Умная вставка текста | [smart-insertion.md](smart-insertion.md) | Почему правится только первая буква и ведущий пробел, как определяется конец предложения, аббревиатуры и исключения |
| Панель спецсимволов | [special-characters-tray.md](special-characters-tray.md) | Выбор ближайшего символа и расширенная до краёв клавиатуры область выбора |
| Отложенная крашлитика | [crash-reporting.md](crash-reporting.md) | Почему runtime-отчётность о сбоях отключена в сборке |
