# Транскрипция файла и повторная отправка

Раздел описывает два действия с аудио помимо обычной записи: распознавание выбранного аудиофайла и повторную отправку последнего аудио.

Связанный раздел: [Голосовая сессия и возврат к клавиатуре](voice-session.md).

## Термины

- **Транскрипция файла** — распознавание выбранного пользователем аудиофайла вместо записи с микрофона.
- **Повторная отправка** — отправка на распознавание последнего корректного аудио.
- **Корректное аудио** — ранее записанное или выбранное аудио, пригодное для распознавания.

## 1. Транскрипция файла

Транскрипция файла запускается отдельной кнопкой. У кнопки записи нет скрытого действия загрузки файла по долгому нажатию.

Выбор файла сразу запускает его распознавание.

Если пользователь выбирает транскрипцию файла во время записи или паузы, текущая запись сначала отменяется, затем открывается выбор файла. После выбора файл сразу отправляется на распознавание.

Кнопка транскрипции файла скрывается только когда функция выключена в настройках. Если функция включена, но действие сейчас недоступно, кнопка показывается в неактивном виде, а соседние элементы не смещаются.

После завершения транскрипции файла клавиатура остаётся на экране даже при включённом возврате к предыдущей клавиатуре.

## 2. Повторная отправка

Повторная отправка отправляет последнее корректное аудио.

Удаление или сброс текущей записи не делает только что удалённый фрагмент целью повторной отправки.

Если повторная отправка включена, но корректного аудио нет, кнопка остаётся на своём месте в неактивном виде. Она не скрывается, потому что скрытие приводит к смещению разметки.

Нажатие повторной отправки во время записи или паузы сначала отменяет текущую запись, затем отправляет предыдущее корректное аудио.
