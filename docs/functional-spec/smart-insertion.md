# Умная вставка текста

Раздел описывает, как распознанный текст корректируется в момент вставки в поле ввода: какие изменения система вносит в первую букву и в пробел перед текстом и чего она сознательно не трогает.

Связанный док разработки: [Умная вставка текста](../development/smart-insertion.md).

## Термины

- **Обычная вставка** — вставка распознанного текста в текстовое поле через клавиатуру VoiceKB.
- **Первая буква** — первая буквенная позиция во вставляемом тексте (пропуская ведущие знаки препинания и пробелы).
- **Завершённое предложение** — текст перед курсором заканчивается символом конца предложения, возможно за закрывающими кавычками или скобками.
- **Аббревиатура** — первое слово вставляемого текста, содержащее две и более заглавные буквы.
- **Чёрный список** — заданный пользователем список слов, регистр которых при вставке не меняется.
- **Ведущий пробел** — один пробел, который система может добавить перед вставляемым текстом.

## 1. Область применения

Умная вставка применяется только к обычной вставке распознанного текста через клавиатуру. Она не применяется к голосовому вводу в браузере, который используется для поиска или одноразового распознавания.

Настройки умной вставки задаёт пользователь; каждое правило ниже действует только при включённой соответствующей настройке.

## 2. Регистр первой буквы

Система может изменить регистр только первой буквы вставляемого текста. Решение принимается по тексту, стоящему перед курсором:

- Если предыдущий текст завершает предложение (или перед курсором ничего нет), первая буква делается заглавной.
- Если предыдущий текст не завершает предложение, первая буква делается строчной.
- Если строка перед курсором выглядит как маркер списка или как маркер цитаты, первая буква делается заглавной.

## 3. Аббревиатуры и исключения

Если первое слово вставляемого текста является аббревиатурой, его регистр сохраняется без изменений.

Если первое слово входит в чёрный список, его регистр также сохраняется без изменений. По умолчанию чёрный список содержит слово «I».

## 4. Ведущий пробел

Система может добавить один пробел перед вставляемым текстом, чтобы фрагмент аккуратно присоединился к предыдущему тексту.

Ведущий пробел не добавляется, если предыдущий текст уже заканчивается пробелом или сам фрагмент начинается с пробела, если предыдущий символ — открывающая скобка или кавычка, а также если фрагмент начинается со знака препинания.

## 5. Что не меняется

Умная вставка изменяет только первую букву и наличие ведущего пробела. Остальной вставляемый текст — включая пунктуацию, регистр прочих слов и содержимое — не изменяется.
