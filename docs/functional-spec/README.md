# Реестр функциональной спецификации

Каждый раздел ФС описывает ТОЛЬКО пользовательское взаимодействие и наблюдаемое поведение системы. Новый раздел создаётся из шаблона `docs/templates/functional-spec-template.md` и обязательно добавляется в таблицу ниже.

| Раздел | Файл | Описание |
| --- | --- | --- |
| Обзор продукта и общие принципы | [overview.md](overview.md) | Чем является VoiceKB, запись до явного завершения, политика сообщений пользователю |
| Голосовая сессия и возврат к клавиатуре | [voice-session.md](voice-session.md) | Состояния записи, мгновенный старт записи, возврат к предыдущей клавиатуре, поведение при внутренних действиях |
| Умная вставка текста | [smart-insertion.md](smart-insertion.md) | Как корректируется регистр первой буквы и ведущий пробел при вставке распознанного текста |
| Транскрипция файла и повторная отправка | [file-transcription-resend.md](file-transcription-resend.md) | Распознавание выбранного аудиофайла и повторная отправка последнего корректного аудио |
| История распознаваний | [history.md](history.md) | Список сохранённых распознаваний: прослушивание, копирование, повторная обработка, удаление, срок хранения |
| Спецсимволы по долгому нажатию Enter | [special-characters.md](special-characters.md) | Выбор и вставка специального символа перемещением пальца по панели |
| Голосовой ввод по запросу приложения | [browser-voice-input.md](browser-voice-input.md) | Отдельный компактный диалог распознавания для поиска и одноразового ввода |
