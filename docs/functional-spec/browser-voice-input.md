# Голосовой ввод по запросу приложения

Раздел описывает отдельный сценарий голосового ввода, когда приложение (например, браузер) само запрашивает распознавание речи — обычно для поиска или одноразового ввода.

Связанный раздел: [Умная вставка текста](smart-insertion.md).

## Термины

- **Запрос распознавания** — обращение приложения к системе с просьбой распознать речь и вернуть текст.
- **Компактный диалог** — отдельное окно голосового ввода по центру экрана, не являющееся клавиатурой.

## 1. Отдельный диалог

По запросу распознавания голосовой ввод показывается компактным диалогом по центру экрана, а не поверхностью клавиатуры.

Диалог использует те же состояния записи и тот же список языков, что и клавиатура.

## 2. Пауза при выборе языка

Открытие выбора языка во время активной записи ставит запись на паузу. Запись возобновляется только после явного действия пользователя.

## 3. Отличия от обычной вставки

Умная вставка текста в этом сценарии не применяется, потому что он обычно используется для поиска или одноразового распознавания.
